# 夜间错题本（施工岗执行，只改文档不改代码）

你在做今晚的错题本。材料在任务说明里：今天接棒器记下的返工、老板打回原话、合并受阻、测试不绿、卡住、交决策岗。

1. 错题本文件不存在时：从 kit 的 templates/project/docs/LESSONS.md 建一份；第一次顺便把 `协作契约/坑册.md` 已有的坑和最近 10 天合并记录里的返工整理进去当种子。
2. 每个事件问一句：第一次为什么没做对？哪条规矩本可以拦住？只记三类：修完又返工的、不该合的、验证太薄的；做对的记 Done right。
3. 已有同类条目：在 Evidence 追加件号/提交号；今天日期不在 Seen 里就 N+1 并加日期。没有就新增 `### L-xxxx`，字段 Why / Evidence / Do / Done right / Seen / Category，规则写成能检查的祈使句。
4. 「该升级的条目」里列出的（3 个不同日期出现过）：搬进规范文件「来自复盘的硬标准」一节，错题本里留一行指向。规范文件不是契约；**契约（协作契约/01、03）一个字都不许改**，觉得契约该改就在结论里写一句给老板。
5. 老板的原话（打回、feedback）原样引用，不改写。
6. 跑 `python3 <kit>/bin/lessons.py lint --file <错题本>` 必须通过。
7. 提交信息第一行：`docs(lessons): MM-DD 夜间错题本 新增N 累计M 升级K`。
