# 切换清单（U10 部署完成后，同一天执行）

前提：老板已批准 V2.0 五条修订，并同意安装 Orca。

1. 备份：把现行 `协作契约/01-契约-AGENT-CONTRACT.md`、`03-验收队列协议.md` 复制到 `协作契约/备份/V1.0-<日期>/`。
2. 装套件：`bash kit/install.sh` 检查 → 补缺 → `bash kit/install.sh --apply`；Orca 里打开 Orchestration；手机扫码配对。
3. 先空跑：用假工人（`kit/mock/`）在副本仓库跑一遍，`tubu status` 三个闸门都出现。
4. 替换契约：把本目录两份文件覆盖到 `协作契约/`，在 `待批准变更清单.md` 签署 V2.0。
5. 更新各岗位启动 prompt 里引用的条款号（§0、§3.4、§3.5、§7、§11.7、§12）。
6. 冻结 wb-issues 面板为只读历史。
7. 真跑第一件：挑一件非 UI 小任务，看施工→验收→合并全自动走完；再挑一件 UI 小件验证「看效果」。

回退：`launchctl unload ~/Library/LaunchAgents/com.tubu.autopilot.plist`，把备份的 V1.0 两份文件拷回，按老办法手贴继续。

## 补充（多项目版）
- 第 2 步装好后用 `tubu import TB --name 土布 --path <tubu-platform 路径>` 导入，按它打印的提示核对测试命令和 GitHub 仓库。
- 面板：`tubu panel`，确认左上角能切到「土布」，「全部待办」里能看到看效果闸门。
