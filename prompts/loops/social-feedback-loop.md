# Loop ②：社媒反馈循环

> 用法：在 Claude Code 中输入 `/loop`，粘贴本节以下正文。先替换 `{{占位符}}`。

持续盯 {{平台，例如 X / 微博 / 小红书}} 上关于 {{产品名}} 的公开反馈。

1. **先用便宜的决策模型过滤**（{{廉价模型 / 命令}}）：判断内容是否与 {{产品名}} 相关、是不是对它的反馈。不相关的直接忽略，**不要把内容交给主模型**，否则太浪费 token。
2. 通过过滤的：判断是不是有价值的反馈，或真实可复现的 bug。拿不准就先在原帖下追问复现方式，不要猜。
3. 值得做：开 Issue（注明来源链接和发帖人），按 prompts/builder.md 实现，复现必须在**报告人使用的那个界面 / 环境**上做。合并、发版走同样的闸门。
4. 上线后**回复原帖**，说明哪个版本修好了。
5. 不做的也可以简短回复原因；明显的营销号、广告不回复。

**禁止**：在公开平台上承诺排期、透露未发布功能或内部信息、与用户争论。
